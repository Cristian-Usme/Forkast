# Forkast

Asistente inteligente de planificación alimentaria que genera menús semanales y listas de compra optimizadas para personas que viven solas, reduciendo desperdicio de alimentos y gasto en el mercado.

## Estructura

```
.
├── frontend/
└── backend/
```

## Frontend

```
cd frontend
npm i
npm run dev
```

## Backend

```
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\uvicorn app.main:app --reload
```
